# Fractional Memcapacitor

This package contains a refactored version of the Biolek fractional-order memcapacitor implementation from the original script.

## Structure

- model.py: BiolekMemcapacitor class and simulation logic
- validation.py: alpha validation and hysteresis-area checks
- plotting.py: plotting helpers for the generated signals
- examples/demo.py: entry point that reproduces the original script's main behavior
